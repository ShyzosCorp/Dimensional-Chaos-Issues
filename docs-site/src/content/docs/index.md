The [mod](https://www.curseforge.com/minecraft/mc-mods/dimensional-chaos) provides the OneBlock, island borders, gateways and escape mechanics. The [OneBlock modpack](https://www.curseforge.com/minecraft/modpacks/dimensional-chaos-oneblock) adds the other mods and pack settings used for the full survival progression. Quests and teams use supported Slate integrations; extra dimensions need their own mods.

Playing with friends? Read [Multiplayer](./multiplayer/) before joining a team. For problems, try [Troubleshooting](./troubleshooting/) or [choose an issue form](https://github.com/ShyzosCorp/Dimensional-Chaos-Issues/issues/new/choose). Use Mod for the custom mod itself, or Modpack for pack settings, recipes and conflicts between installed mods.

These guides are checked for **1.1.0 Beta**. Older worlds can keep settings and OneBlock pools from the version that created them.
