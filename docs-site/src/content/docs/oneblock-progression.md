---
title: "OneBlock progression"
description: "The seven OneBlock phases, mined-block thresholds, tools and shared six-slot reserve in Dimensional Chaos 1.1.0 Beta."
---

The OneBlock changes its resource pool as you mine. This is a mod feature; the official pack supplies the other mods used by its pools and crafting progression.

For new worlds using the 1.1.0 pools, phases start at these total mined-block counts:

| Phase | Blocks mined |
| --- | ---: |
| Beginnings | 0 |
| Survival | 128 |
| Engineering | 512 |
| Industry | 1,536 |
| Arcane | 4,096 |
| Dimensional Chaos | 8,192 |
| Advanced Survival | 16,384 |

Use `/dc oneblock info` to see your actual progress. A team's island shares one counter. Older worlds keep their saved pools, so updating the mod doesn't necessarily give them the same resources as a new world.

Use tools that can harvest the current block. The OneBlock is meant to be mined by a real player in Survival; machines and fake players don't advance it.

If your inventory fills up, drops go into the island's six-slot reserve. Sneak and right-click the OneBlock with an empty hand to open it, or use `/dc oneblock cache`. Team members share this reserve. If both inventory and reserve are full, extra drops fall on the ground, so clear space regularly.

The seven resource phases are separate from the eight [island expansion tiers](../island-expansion/).
