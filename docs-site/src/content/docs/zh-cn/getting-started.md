创建一个生存模式世界，确认世界类型是 **维度混沌 - 单方块（虚空）**。第一次打开创建新世界界面时，它就是默认选项。

挖掘 OneBlock（游戏内称“单方块”）获取最初的资源，每次挖掉后它都会重新出现。走向传送门之前，先做好工具，再搭一个安全的平台。每种方块都要用合适的工具：有些方块用什么都能挖掉，但只有用对工具才会掉落。

在整合包里，Slate 任务书就是你的向导。它共有 120 个任务，其中包括八个岛屿扩张章节，可以扩大你的岛屿并开放新维度。这些任务依赖整合包里的模组，所以只装模组本体的话，并不是所有任务都能完成。

刚开始时，这几个命令很实用：

| 命令 | 显示内容 |
| --- | --- |
| `/dc status` | 今天的目的地、当前章节还需要前往的维度，以及岛屿下一个解锁的维度 |
| `/dc oneblock info` | 你的 OneBlock 阶段、已挖掘方块数和距下一阶段的进度 |
| `/dc island` | 你的岛屿等级和下一级 |
| `/dc border` | 你的岛屿边界 |
| `/dc expedition` | 你的远征或逃脱状态 |

传送门在白天开放。一旦踏进去，你有 15 分钟时间返回。第一次出发前，请先阅读[维度远征](../dimensional-expeditions/)。
