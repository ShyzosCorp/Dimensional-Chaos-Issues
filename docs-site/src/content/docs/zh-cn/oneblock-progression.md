OneBlock 给出的东西会随着你的进度而变化，一共有七个阶段。挖掘的方块数达标，**或者**岛屿达到对应等级，就会进入下一阶段，以先达成的为准。所以任务章节永远不需要等你多挖方块。

| 阶段 | 已挖掘方块 | 或岛屿等级 |
| --- | ---: | ---: |
| 起步 | 0 | – |
| 生存 | 128 | 1 |
| 工程 | 512 | 3 |
| 奥术 | 1,536 | 4 |
| 工业 | 4,096 | 5 |
| 维度混沌 | 8,192 | 6 |
| 进阶生存 | 16,384 | 7 |

后期阶段会保留前期阶段的关键矿石，所以你不会缺锇这类资源。

用 `/dc oneblock info` 查看当前进度。同一队伍共用一个 OneBlock 和一个计数器。1.1.2 之前创建的世界会保留创建时的阶段设置。

必须由你亲自在生存模式下，用能采集当前方块的工具来挖。机器和假玩家不会推进进度。

如果背包满了，掉落物会进入岛屿的六格储备（单方块储备）。空手潜行并右键点击 OneBlock 即可打开，也可以使用 `/dc oneblock cache`。储备由整个队伍共享。背包和储备都满了的话，掉落物会掉在地上，所以记得时常清空。

这些阶段与八个[岛屿扩张等级](../island-expansion/)相互独立，不过提升等级可以提前开启某个阶段。
