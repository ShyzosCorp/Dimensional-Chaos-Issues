新岛屿一开始是半径 16 的方形边界。靠近边缘时会出现青色的边界墙，并且由服务器强制执行：你无法越过它建造或行走。

## 解锁等级

每个等级在 Slate 任务书中都有一个扩张章节。章节的最后一个任务 **岛屿扩张 1** 到 **8**，会在该章节的关键任务完成后开放。然后勾选 **扩张岛屿** 即可，不需要消耗任何物品。章节中的其他任务都是可选的。

等级按顺序解锁。每次边界半径增加 8 格，等级 8 时达到 80。等级属于岛屿，所以整个队伍共享，而且永远不会下降。`/dc island` 会显示你的当前等级和下一级。

| 等级 | 章节 | 边界半径 | 关键任务 |
| ---: | --- | ---: | --- |
| 1 | 初次尝试 | 24 | 第一批原木、石制工具、熔炉、通往传送门的桥、第一次远征、及时回家 |
| 2 | 幸存者之岛 | 32 | 铁、铁镐、盾牌、造访暮色森林 |
| 3 | 神秘之根 | 40 | 下界、下界石英、下级精华、黑曜石 |
| 4 | 齿轮与蒸汽 | 48 | 锌、安山合金、齿轮、水车、动力辊压机 |
| 5 | 奥术研习 | 56 | 幽暗地底、新手法术书、铭文台、青金石 |
| 6 | 工业虚空 | 64 | 采矿世界、锇、冶金灌注机、钢、基础控制电路、富集仓 |
| 7 | 裂隙彼端 | 72 | 末地、末影珍珠、凋灵骷髅 |
| 8 | 维度精通 | 80 | 凋灵、下界之星、信标、精英控制电路 |

每次扩张的奖励都是为下一章准备的物资包：进入 Create 之前给安山合金，接触魔法之前给火把和青金石，开始 Mekanism 之前给锇和红石，前往末地之前给金苹果和末影珍珠，最后还有召唤凋灵用的凋灵骷髅头颅和灵魂沙。此外你还会获得经验和维度碎片。

扩张会给你更多建造空间，但不会自动填充新区域。它还可能提前开启某个 [OneBlock 阶段](../oneblock-progression/)。

## 新维度

你的等级决定了传送门可以带你去哪些维度：

| 维度 | 岛屿等级 |
| --- | ---: |
| 暮色森林 | 0 |
| 天境 | 1 |
| 下界 | 2 |
| 幽暗地底 | 4 |
| Allthemodium 采矿世界 | 5 |
| 末地 | 6 |
| Allthemodium 异界 | 6 |
| 彼方（Deeper and Darker） | 7 |

解锁维度会把它加入传送门的轮换；你不能随时指定前往。当某个章节需要某个维度时，传送门会优先前往，但最多隔天一次。只有安装了对应模组，维度才会出现。使用自定义设置的服务器可能有所不同。

等级越高，挑战也越大：今日威胁的怪物波次更凶猛，修复裂隙需要更多碎片，裂隙守卫的波次也更庞大。

## 没有 Slate Quests 时

边界和等级由模组本体提供，但通过任务解锁需要 Slate Quests 和整合包的任务书。没有它们时，只有管理员能用 `/dc island tier set <tier>` 修改等级。
