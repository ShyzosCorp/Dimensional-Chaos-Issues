Dimensional Chaos 1.1.2 Beta 运行于 Minecraft 1.21.1，需要 NeoForge 和 Java 21。

## OneBlock 整合包

通过 CurseForge App 安装 [Dimensional Chaos – OneBlock](https://www.curseforge.com/minecraft/modpacks/dimensional-chaos-oneblock)。它会自动配置好 NeoForge，并且已经内置模组本体，所以不要再额外添加一份。请给游戏分配至少 6 GB 内存。

为整合包单独建一个配置文件，更新前记得备份世界。

## 在自己的整合包中使用模组

把 [Dimensional Chaos](https://www.curseforge.com/minecraft/mc-mods/dimensional-chaos) 添加到 Minecraft 1.21.1 的 NeoForge 配置文件中。它需要以下模组（以及它们各自的前置）：

| 模组 | 最低版本 |
| --- | --- |
| Create | 6.0.0 |
| Mekanism | 10.7.0 |
| Ars Nouveau | 5.0.0 |
| Powah! | 6.0.0 |

OneBlock 阶段会用到这些模组的方块。本指南中提到的任务书和队伍功能由 Slate Quests 和 Slate Teams 提供。单装模组不会安装整合包的其他内容及额外维度；未安装的维度会直接从轮换中剔除。

多人游戏时，客户端和服务器的模组版本与整合包版本必须一致。模组需要在两端都安装。服主应使用服务器包，而不是把所有客户端模组都复制到服务器上。
