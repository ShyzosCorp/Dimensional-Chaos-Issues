These instructions are for 1.1.0 Beta: Minecraft 1.21.1, NeoForge and Java 21.

## OneBlock modpack

Install [Dimensional Chaos – OneBlock](https://www.curseforge.com/minecraft/modpacks/dimensional-chaos-oneblock/files/9278157) through the CurseForge App, or import its ZIP as a modpack profile. The pack selects NeoForge 21.1.263 and includes the custom mod. You don't need to add another copy of Dimensional Chaos.

Keep a separate profile for this pack. Before updating an existing profile, back up its worlds and settings.

## Mod in your own pack

Install [Dimensional Chaos 1.1.0 Beta](https://www.curseforge.com/minecraft/mc-mods/dimensional-chaos/files/9277731) in a Minecraft 1.21.1 NeoForge profile. The release declares these required mods, in addition to their own dependencies:

| Mod | Minimum version |
| --- | --- |
| Create | 6.0.0 |
| Mekanism | 10.7.0 |
| Ars Nouveau | 5.0.0 |
| Powah! | 6.0.0 |

The built-in OneBlock pools use blocks from these mods. Slate Quests and Slate Teams provide the quest and team integrations described in this guide; they aren't replacements for the required mods above. Installing the custom mod alone doesn't install the whole OneBlock pack or its extra dimensions.

For multiplayer, use matching mod and pack versions on the client and server. The custom mod belongs on both sides. Server owners should use the matching server setup rather than copying every client mod onto a server.
