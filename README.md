# Dimensional Chaos — Mod Issue Tracker

Public bug reports and feature requests for the **Dimensional Chaos** Minecraft mod by **ShyzosCorp**.
The mod targets **Minecraft 1.21.1 with NeoForge**.

[Get the mod on CurseForge](https://www.curseforge.com/minecraft/mc-mods/dimensional-chaos)

## Report a bug or request a feature

Search existing open and closed issues, then [choose a structured issue form](https://github.com/ShyzosCorp/Dimensional-Chaos-Issues/issues/new/choose).
Use **Bug report** for problems and **Feature request** for improvements to mod functionality.

For bugs, include your Dimensional Chaos mod version, Minecraft and NeoForge versions,
singleplayer/LAN/dedicated-server environment, operating system, reproduction steps,
and expected versus actual behavior. Include relevant logs or crash reports when available.
If using the official companion modpack, include its version and mention mod-list changes.

**Reports and attachments are public.** Review logs, crash reports and screenshots before posting.
Remove credentials, session data, personal paths, IP addresses and other private information.
Do not upload worlds, player data or launcher account files.

## Scope

This tracker covers **Dimensional Chaos mod functionality**, including compatibility problems involving the mod.
Companion modpack installation, packaging, pack-only configuration and content issues belong on
**the modpack's own support tracker**. Do not send mod bug reports to the modpack tracker.

## Triage

New reports receive `needs-triage` and either `bug` or `enhancement`.
Maintainers may use `needs-reproduction`, `confirmed` and `compatibility` during investigation.
`fixed` means a fix has been implemented; check the issue for its availability and version.
`duplicate` links to an existing report; `wontfix` records a decision not to implement a change.
