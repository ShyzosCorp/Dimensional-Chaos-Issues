---
title: "Installation"
description: "Install the OneBlock modpack, or add the Dimensional Chaos mod to your own NeoForge pack. Requirements for 1.1.2 Beta."
---

Dimensional Chaos 1.1.2 Beta runs on Minecraft 1.21.1 with NeoForge and Java 21.

## OneBlock modpack

Install [Dimensional Chaos – OneBlock](https://www.curseforge.com/minecraft/modpacks/dimensional-chaos-oneblock) from the CurseForge App. It sets up NeoForge and already includes the mod, so don't add another copy. Give the game at least 6 GB of memory.

Keep a separate profile for the pack, and back up your worlds before updating.

## The mod in your own pack

Add [Dimensional Chaos](https://www.curseforge.com/minecraft/mc-mods/dimensional-chaos) to a Minecraft 1.21.1 NeoForge profile. It needs these mods (and their own dependencies):

| Mod | Minimum version |
| --- | --- |
| Create | 6.0.0 |
| Mekanism | 10.7.0 |
| Ars Nouveau | 5.0.0 |
| Powah! | 6.0.0 |

The OneBlock phases use blocks from these mods. Slate Quests and Slate Teams provide the quest book and teams described in these guides. The mod alone doesn't install the rest of the modpack or its extra dimensions; dimensions that aren't installed are simply left out of the rotation.

For multiplayer, the client and server need the same mod and pack versions. The mod goes on both sides. Server owners should use the server pack rather than copying every client mod onto the server.
