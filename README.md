# Dimensional Chaos — Mod & Modpack Issue Tracker

Public bug reports and feature requests for two **ShyzosCorp** projects targeting **Minecraft 1.21.1 with NeoForge**:

- **[Dimensional Chaos (Mod)](https://www.curseforge.com/minecraft/mc-mods/dimensional-chaos)** — custom Minecraft NeoForge gameplay systems.
- **[Dimensional Chaos – OneBlock (Modpack)](https://www.curseforge.com/minecraft/modpacks/dimensional-chaos-oneblock)** — a complete modded survival experience combining the custom mod with other Minecraft mods, configurations and progression content.

## Report a bug or request a feature

Search existing open and closed issues, then [choose a structured issue form](https://github.com/ShyzosCorp/Dimensional-Chaos-Issues/issues/new/choose).

| Project | Report a bug | Request a feature |
| --- | --- | --- |
| Dimensional Chaos mod | [Mod — Bug Report](https://github.com/ShyzosCorp/Dimensional-Chaos-Issues/issues/new?template=01-bug-report.yml) | [Mod — Feature Request](https://github.com/ShyzosCorp/Dimensional-Chaos-Issues/issues/new?template=02-feature-request.yml) |
| Dimensional Chaos – OneBlock modpack | [Modpack — Bug Report](https://github.com/ShyzosCorp/Dimensional-Chaos-Issues/issues/new?template=03-modpack-bug-report.yml) | [Modpack — Feature Request](https://github.com/ShyzosCorp/Dimensional-Chaos-Issues/issues/new?template=04-modpack-feature-request.yml) |

For bugs, include the affected mod or modpack version, Minecraft and NeoForge versions (if known),
singleplayer/LAN/dedicated-server environment, operating system, reproduction steps,
and expected versus actual behavior. Include relevant logs or crash reports when available.
For modpack reports, include your installation method and mention mods manually added, removed or updated.
For memory or performance problems, include allocated RAM. A crash report is only useful when a crash occurred.

**Reports and attachments are public.** Review logs, crash reports and screenshots before posting.
Remove credentials, session data, personal paths, IP addresses and other private information.
Do not upload worlds, player data or launcher account files.

## Scope

Choose **Mod** for a bug isolated to the Dimensional Chaos custom mod itself, or a feature for its gameplay systems.
Choose **Modpack** for conflicts involving installed mods, broken pack configurations or recipes,
OneBlock pack progression/content, or problems isolated to a dedicated server pack.
Custom-mod compatibility reports remain welcome in the Mod form when isolated to that mod.
If unsure, use the Modpack form and describe your setup; maintainers can help classify the report.

## Triage

New reports receive `needs-triage`, either `bug` or `enhancement`, and the matching
`project:mod` or `project:modpack` scope label.
Maintainers may use `needs-reproduction`, `confirmed` and `compatibility` during investigation.
`fixed` means a fix has been implemented; check the issue for its availability and version.
`duplicate` links to an existing report; `wontfix` records a decision not to implement a change.
