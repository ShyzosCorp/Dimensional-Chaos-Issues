# Repository notes

This is the public support tracker for the Dimensional Chaos mod and OneBlock modpack.
Keep the four forms, links, field IDs, required flags, title prefixes and labels working.
Open a PR for changes and wait for owner approval before merging.

## Writing

Use short, straightforward English for READMEs, PR titles and descriptions, commit messages,
issue templates, changelogs, release notes and other public text. Be friendly and specific.
Skip marketing language, canned introductions, repeated explanations and long checklists.
Use headings, bullets and bold text only when they help. Describe what changed and mention
checks briefly, only if they ran. Keep technical facts, requirements and privacy guidance accurate.
