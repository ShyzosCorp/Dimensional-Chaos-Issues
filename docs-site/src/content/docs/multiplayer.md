---
title: "Multiplayer"
description: "Play Dimensional Chaos with friends: shared islands, OneBlock progress and the team-join inventory reset warning."
---

Use the same pack release as the server. The modpack includes the Slate Teams integration used for shared islands; a custom installation needs that supported integration too.

Start a team with `/dc team create <name>`, then invite friends through the supported Slate Teams interface. The invited player gets a confirmation prompt. `/dc team info` shows their team information.

**Joining another team resets your carried inventory, accessories, Ender Chest, XP and unrecovered graves once.** Read the warning before using the confirmation link or `/dc team confirm <name>`. Storage blocks you placed stay where they are. Finish your expedition before joining.

Team members share an island, OneBlock progress, its reserve and expansion tier. Quest progress and team rewards use the pack's Slate settings.

Use the in-game prompts for leaving, kicking or changing ownership. If a team change is refused, read the message and ask the server owner for help. Don't work around it by editing player data or deleting transfer files.
