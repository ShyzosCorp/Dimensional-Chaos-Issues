Le [mod](https://www.curseforge.com/minecraft/mc-mods/dimensional-chaos) apporte le OneBlock, les bordures d’île, le portail et tout le système d’évasion. Le [modpack OneBlock](https://www.curseforge.com/minecraft/modpacks/dimensional-chaos-oneblock) ajoute les autres mods, le livre de quêtes et les réglages du pack pour l’expérience de survie complète.

Tu joues avec des amis ? Jette un œil à [Multijoueur](./multiplayer/) avant de rejoindre une équipe. Un souci ? Regarde [Dépannage](./troubleshooting/) ou [ouvre un ticket](https://github.com/ShyzosCorp/Dimensional-Chaos-Issues/issues/new/choose).

Ces guides sont à jour pour la **1.1.2 Beta**. Les mondes créés avec une version plus ancienne gardent certains de leurs anciens réglages, comme leurs phases de OneBlock.
